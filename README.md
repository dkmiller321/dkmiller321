### Hi, I'm Donald Miller

Senior AI/ML engineer in Melbourne, FL, with about 10 years in software. I build agentic LLM applications and prototypes in Python and TypeScript, and I test them like any other production software. My background is in test automation, CI/CD and computer vision.

#### What I build

- **[LaunchLedger](https://github.com/dkmiller321/launchledger)**: an AI assistant over fictional factory systems, with contracts, guardrails, drift detection and regression evals in CI.
- **[DefPrO](https://github.com/dkmiller321/DefPrO)**: a knowledge graph of public US defense procurement data, with a Claude-powered MCP server for plain-English queries.
- **[Canvas Chat](https://github.com/dkmiller321/canvas-chat)**: self-hosted AI chat where the model writes documents, code and diagrams into a versioned canvas.
- **[agent-home](https://github.com/dkmiller321/agent-home)**: a local chat app over a Strands agent that remembers you across sessions.
- **[fantasy-intelligence-mcp](https://github.com/dkmiller321/fantasy-intelligence-mcp)**: a remote MCP server on Cloudflare Workers that makes Claude a fantasy football analyst.
- **[Livemap](https://github.com/dkmiller321/livemap)**: see every HTTP, database, LLM and agent call in your running app as a live map.

Also: [KitForge](https://github.com/dkmiller321/KitForge) (a versioned registry for Claude Code kits), [Loom](https://github.com/dkmiller321/Loom) (chat plus a workflow builder) and [rental-ops-agent](https://github.com/dkmiller321/rental-ops-agent) (LangChain agent with RAG).

#### Tools

LangGraph, LangChain, CrewAI, Strands, MCP servers, RAG, FastAPI, React/Next.js. GPT, Claude and Gemini models, including audio and image.
