### Hi, I'm Donald Miller

Senior AI/ML engineer in Melbourne, FL. I build LLM applications, MCP servers and RAG systems, and I test them as thoroughly as any other production software.

#### Featured projects

- **[DefPrO](https://github.com/dkmiller321/DefPrO)**: knowledge graph of US defense procurement. Python ETL from USASpending.gov into a BFO/CCO ontology on Apache Jena Fuseki, with a Claude-powered MCP server for plain-English SPARQL queries.
- **[Canvas Chat](https://github.com/dkmiller321/canvas-chat)**: self-hosted AI chat where the model edits documents, code and diagrams through tool calls, with versioning, diffs and branching. Next.js, Postgres, Vercel AI SDK, Playwright.
- **[swarm-lite](https://github.com/dkmiller321/swarm-lite)**: real-time UAV swarm command-and-control dashboard. Go backend with WebSocket telemetry and a React map UI.
- **[databricks-demo](https://github.com/dkmiller321/databricks-demo)**: ontology platform on Databricks with an ONTOP virtual knowledge graph, Django and LLM-assisted exploration.
- **[LANtern](https://github.com/dkmiller321/LANtern)**: local network monitor that tracks devices and shows activity on a web dashboard.
- **[marketsense](https://github.com/dkmiller321/marketsense)**: Next.js app that watches competitor pricing pages and emails alerts on changes.
